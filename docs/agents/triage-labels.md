# Triage labels

Every open issue should have exactly one current triage-state label.

| State | GitHub label | Meaning |
| --- | --- | --- |
| New | `needs-triage` | The report has not been classified or scoped. |
| Clarification | `needs-info` | Meaningful progress requires information from a human. |
| Agent-ready | `ready-for-agent` | Scope and acceptance criteria are suitable for autonomous implementation. |
| Human-ready | `ready-for-human` | A human decision, review, or manual validation is the next action. |
| Closed without implementation | `wontfix` | The repository intentionally will not implement the request. |

Use GitHub's standard `bug`, `enhancement`, and `documentation` labels as type
labels where appropriate. Type labels do not replace the triage-state label.
